# 🛒 Tech-Store-Nepal | Nepali Tech E-commerce Platform

**Tech-Store-Nepal** is a modern, responsive, and full-stack e-commerce web application designed specifically for buying and selling tech gadgets, computer parts, smartphones, and accessories in Nepal. 

The project focuses on localized features such as Nepalese Rupee (NPR) currency support, integration with local payment gateways (eSewa, Khalti, ConnectIPS), and a streamlined checkout flow tailored to Nepali delivery addresses.

---

## ✨ Key Features

### 👤 Customer Facing
* **Tech Catalog & Search:** Filter products by category, brand, price, and specs (RAM, Storage, GPU, etc.).
* **Localized Checkout:** Address selection optimized for major Nepali cities and districts.
* **Payment Integration:** Secure checkout supporting **eSewa**, **Khalti**, **ConnectIPS**, and Cash on Delivery (COD).
* **Cart & Wishlist:** Real-time shopping cart calculation with price breakdown in NPR (रू).
* **Order Tracking:** Track order status from processing to doorstep delivery.
* **User Authentication:** Secure JWT / OAuth authentication with user profile management.

### 🛡️ Admin Dashboard
* **Product Management:** Add, edit, or delete products with specs and multiple images.
* **Inventory Tracking:** Monitor stock levels and receive low-stock alerts.
* **Order Management:** Update order statuses (Pending, Shipped, Delivered) and manage payments.
* **Sales Analytics:** Basic dashboard to view top-selling tech items and daily revenue.
